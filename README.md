# VOLT//FORGE — Gym Website

Portfolio-ready frontend for the VOLT//FORGE fitness brand.

## Pages
- `index.html` — Home
- `programs.html` — Programs
- `classes.html` — Classes
- `trainers.html` — Trainers
- `results.html` — Results / Transformations
- `join.html` — Membership / Join

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Notes
- Frontend-only portfolio project; no authentication or database required.
- Images are loaded from Unsplash URLs.
- Class booking interactions are demo-only.
